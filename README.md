# AGG2025
This repository provides FEniCS code (in Python, legacy FEniCS version 2019.1.0) for simulating abnormal grain growth (AGG) driven by elastic anisotropy, and MATLAB code for computing the effective elastic modulus (diffraction elastic constant) of cubic crystals.

### If you use the FEniCS code, please cite the following papers:
Liu, Y., Zhang, Y., Ding, K., Yang, Y., Barrios, A., Maeder, X., Pierron, O., Liu, X. & Zhu, T. Phase-field modeling of elastically driven abnormal grain growth. arXiv preprint [arXiv:2607.05298](https://arxiv.org/abs/2607.05298) (2026).
